さいたまアート資源マップ 設置・更新手順

1. ZIPを展開し、index.html、assets、data、images等を同じ構成でWeb公開フォルダへ配置します。
2. HTTPSのURLで開きます。ドメイン直下・サブディレクトリのどちらでも設置できます。
3. Node.js、npm、PHP、データベース、URLリライトは不要です。HTMLのダブルクリックによる利用は対象外です。
4. サーバーがHTML、JavaScript、CSS、JSON、WebPを正しいContent-Typeで配信することを確認します。
5. config.json、data/spots.json、index.htmlには再検証されるキャッシュ設定を推奨します。
   assets内のハッシュ付きファイルは長期キャッシュが可能です。

外部通信
- 背景地図: cyberjapandata.gsi.go.jp（国土地理院）。取得できなくても写真付き一覧は利用できます。
- 現在地: ブラウザの位置情報許可が必要です。アプリは位置や住所を永続保存しません。
- 経路案内: 利用者の操作でGoogle Mapsを開きます。選択したスポットと、取得済みの場合は検索起点の座標を渡します。
- 住所検索: 初期設定では無効です。運用主体が利用条件・CORS・精度等を確認した後、config.jsonの
  addressSearch.enabledをtrueにすると、候補選択付き住所検索を利用できます。
  入力住所は設定されたAPIへ送信されます。秘密のAPIキーをconfig.jsonへ書かないでください。
- 設置先にContent-Security-Policyがある場合は、上記とconfig.jsonの外部通信先を許可してください。

データと掲載許可
- review版は正式公開前の確認用です。未連絡11件は含めていませんが、残る対象の許可済みを保証するものではありません。
- release版は掲載管理がapprovedで確認記録のある対象だけを含めます。
- 記事・画像はオープンデータではありません。THIRD_PARTY_NOTICES.txtと出典を保持してください。
- 更新時はソース側の掲載管理・元データを編集し、手順書のコマンドでZIPを再生成します。
- 差し替え前に旧版を公開領域の外へバックアップし、旧画像・旧JSON等が公開領域に残らないようにします。
- リポジトリ全体、保守用ソースZIP、元CSV、掲載管理ファイルは公開フォルダに置かないでください。

公開前確認
- 一覧の最後までスクロールし、最終カードを開ける。
- 検索・0件表示・条件解除・詳細から一覧への復帰が動く。
- スマートフォン・拡大表示・キーボード操作で利用できる。
- 現在地の拒否、地図の通信失敗時にも一覧を利用できる。
- 正式な設置先のサブディレクトリで画像とJSONが読み込める。
