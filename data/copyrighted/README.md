# アーツカウンシルさいたま記事データ（著作物）

`arts_council_saitama_articles.csv` は、アーツカウンシルさいたま「アート資源調査」の記事ページから、タイトル、サブタイトル、記事本文、記事構造、画像URL、ローカル画像パス、基本情報を取得したデータです。

## 重要：オープンデータではありません

- 本CSVには記事本文・画像情報などの著作物が含まれます。
- `data/open_data/111007_public_facility.csv` とは分離して管理してください。
- 本CSVを公開、転載、再配布または二次利用する場合は、アーツカウンシルさいたま公式サイトの著作権表示・利用条件を確認し、必要な許諾を取得してください。
- `images/` には、ビューア表示用として公式掲載画像から作成したWebPを収録しています。長辺最大1280px、品質78で軽量化しています。
- WebP化やリポジトリへの保存によって著作権・利用条件は変わりません。公開、転載、再配布には必要な許諾を確認してください。
- 出典：公益財団法人さいたま市文化振興事業団 アーツカウンシルさいたま
  - https://artscouncil-saitama.jp/library/survey/

## IDによる結合

- `id`：元調査CSVの `id` と一致
- `公開データID`：オープンデータCSVの `ID` と一致（例：`ACS0001`）
- Mapビューアは位置情報CSVと本CSVをブラウザ内で結合し、オープンデータCSVへ著作物を混在させません。

## 主な項目

- 記事タイトル、記事サブタイトル、年度、記事抜粋、記事本文
- 記事セクションJSON：見出しと段落の配列
- アイキャッチ画像URL、画像JSON：公式画像URL・役割・alt・寸法・ローカルWebPパス・変換後寸法・ファイルサイズ
- アイキャッチ画像ローカルパス、ローカル画像件数、WebP合計バイト数
- 基本情報JSON、記事掲載住所、記事掲載電話番号、担当者等、関連リンク
- WordPress投稿ID、スラッグ、公開日時、更新日時、出典URL、取得日
- 著作権区分、権利者表示、利用注記

## 更新方法

記事ページの再取得には次のスクリプトを使用します。

```bash
python3 scripts/scrape_artscouncil_articles.py
python3 scripts/download_article_images.py
```

画像は143点をWebP化しています。取得日は2026-08-02です。公式ページの更新後は再取得し、差分と利用条件を確認してください。
